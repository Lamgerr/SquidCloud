# SquidCloud v12.5 (Upcoming)

**Release Date:** August 1, 2026

> SquidCloud v12.5 focuses on improving productivity, publishing, developer workflows, automation, and file management while introducing powerful new capabilities across the platform.

---

# Supporter Plan Modifications

Beginning with **v12.5**, the Supporter plan will receive the following changes:

- File request limit will be adjusted to **5**
- Static website publishing (via folders) will be included
- Website visitor analytics will be included
- Maximum file size will be adjusted to **12 GB**
- React Picks will be included

## Default Shortcuts

| Shortcut | Action |
|----------|--------|
| **U** | Upload File |
| **N** | New Folder |
| **/** | Focus Search |
| **D** | Download Selected |
| **Delete** | Move Selected to Trash |
| **R** | Rename Selected |
| **S** | Share Selected |
| **P** | Publish Selected |

| **?** | Open Keyboard Shortcut Reference |

Additional shortcuts will also be available throughout the application.

Pressing **?** will open a dedicated keyboard shortcut reference overlay inspired by modern productivity tools.

# Webhook Events *(Premium Only)*

Webhook Events will allow SquidCloud to automatically send HTTP POST requests whenever selected account activities occur.

## Availability

| Plan | Webhook Limit |
|------|---------------|
| Free | Not Available |
| Supporter | 5 |
| Supporter+ | 10 |

## Supported Events

### File Events

- file.uploaded
- file.shared
- file.name *(user-defined filename)*
- file.ext *(selected file extension such as mp3, mp4, etc.)*
- file.moved
- file.deleted

### Website Events

- site.published
- site.unpublished
- site.redeployed
- site.archived
- site.unarchived

### Share Events

- share_link.accessed
- share_link.revoked

### Pipeline Events

- pipeline.completed
- pipeline.failed

### API Events

- api_tokens.quota_warning *(triggered at a user-defined percentage threshold)*

Every webhook event will use a consistent JSON payload structure containing:

- Event name
- ISO8601 timestamp
- Account ID
- Event-specific data

Users will be able to subscribe to all events or only selected events.

Each webhook will include its own secret signing key, allowing receiving servers to verify that requests originated from SquidCloud.

# Custom 404 Pages

Folder-based published websites will support custom 404 pages.

If a **404.html** file exists in the root directory of a published folder, SquidCloud will automatically serve it whenever visitors access a non-existent route.

No additional configuration will be required.

The custom page may reference any CSS or JavaScript files already included inside the published folder using relative paths.

---

# File & Folder Notes

Private notes will be supported for every file and folder.

Notes will remain visible only to the owner and will never be exposed through sharing or published websites.

## Limits

| Plan | Notes per File/Folder |
|------|------------------------|
| Free | 5 |
| Supporter | 20 |
| Supporter+ | 30 |

## Features

- Plain text notes
- No character limit
- Searchable through SquidCloud Spotlight Search
- Persist through renames, moves, and copies
- Never included in share links or published websites
- Note indicator displayed on file and folder cards

Multiple notes will be supported.

A dedicated **Notes** panel will be accessible from:

- File Context Menu
- Folder Context Menu
- Mobile File Sheet
- Mobile Folder Sheet

Selecting **Notes** will open a side panel with an optional fullscreen mode.

---

# Empty State Improvements

Empty folders, search results, pipeline lists, published websites, and other empty experiences will receive thoughtful illustrations alongside meaningful actions.

Instead of displaying generic "No items" messages, every empty state will help guide users toward the next appropriate action.

# SquidEmbed — Native File & Folder Embedding

## Overview

SquidEmbed will introduce native embedding for files and folders.

Every file and folder will receive a one-click embeddable component that can be inserted into websites, portfolios, blogs, documentation, Notion pages, and web applications.

Embeds will be rendered entirely by SquidCloud's infrastructure with minimal setup required.

---

## Embedding Workflow

### Step 1

Right-click any file or folder and choose **Embed**.

The option will be available from:

- File Context Menu
- Folder Context Menu
- Mobile File Sheet
- Mobile Folder Sheet

### Step 2

The Embed modal will include:

- Interactive live preview
- Customization options
- Ready-to-copy embed code
- Instant copy action

### Step 3

Paste the generated embed into any supported website.

No additional configuration will be required.

---

# Embed Types

## File Embed

Individual files will automatically render using dedicated viewers based on file type.

Supported content includes:

- Images
- Videos
- Audio
- PDF documents
- Source code
- Markdown
- Plain text
- Generic file previews

---

## Folder Embed

Folder embeds will provide a fully interactive file browser.

Available layouts:

- Grid View
- List View
- Gallery View

Features include:

- Inline previews
- Folder navigation
- Breadcrumb navigation
- Folder search
- Sorting by name, size, and date
- Smooth animated transitions

# Live Customization

The Embed modal will include a live preview.

Every customization will update instantly before the embed code is copied.

---

# Privacy & Access Control

Embeds will always respect file and folder visibility settings.

Private content will display a placeholder rather than exposing protected data.

Owners will be able to revoke embeds at any time, immediately disabling every embedded instance.

Additional capabilities will include:

- Embed view analytics
- Branding-free embeds for Supporter and Supporter+ users
- Small "Powered by SquidCloud" branding on Free embeds

---

# Embed Modal Layout

The Embed interface will consist of three panels.

## Live Preview

Displays an interactive preview exactly as visitors will see it.

## Customization

Contains appearance and behavior settings with real-time updates.

## Code

Provides:

- Runtime script
- Embed component
- Individual copy actions
- Copy All functionality

# Why SquidEmbed

SquidEmbed will extend SquidCloud beyond traditional cloud storage by transforming files and folders into interactive web components.

Benefits include:

- Passive brand visibility through Free embeds
- Interactive file sharing beyond SquidCloud
- Folder embeds functioning as lightweight file-based content management
- One-click integration into virtually any website
- A polished native embedding experience built specifically for cloud-hosted content
