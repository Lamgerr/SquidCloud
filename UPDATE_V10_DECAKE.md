# SquidCloud v10 - Decake Update

**Release Date:** 10 February 2026  
**Codename:** Decake  
**Version:** 10.0.0

---

## Overview

The Decake Update represents a major leap forward in SquidCloud's evolution, introducing a completely redesigned dashboard experience, advanced file organization features, and a modern aesthetic inspired by the latest design trends from Linear, Notion, and Vercel.

---

## New Features

### Dashboard Redesign

#### Collapsible Sidebar
- **New collapsible sidebar** with smooth animations
- Toggle between expanded and icon-only views
- Persists state across sessions
- Cleaner navigation with organized sections

#### Modern File Cards
- **Flat design** with subtle borders
- Removed heavy hover effects for cleaner UX
- Color stripe indicators for visual organization
- Star badges for bookmarked items

#### Improved Layout
- Maximum width container for better readability
- Better spacing and visual hierarchy
- Glassmorphism effects with backdrop blur
- Responsive design improvements

---

### File Organization Features

#### Bookmark System
- **Add files and folders to favorites** with one click
- Quick access section in sidebar
- Star indicators on bookmarked items
- Easily remove bookmarks with hover action

#### Color Coding
- **8 color options** for files and folders:
  - None, Red, Orange, Yellow, Green, Blue, Purple, Pink
- Color picker in context menu
- Persistent color tags stored locally
- Visual color stripes on cards

---

### Archive Viewer
- **View contents of ZIP files** without extracting
- Browse archive file structure
- See file sizes and paths
- Download individual files or full archive

---

- No more emojis in UI elements

## Migration Notes

This update is backward compatible. All existing files, folders, and settings are preserved. New features are opt-in:

- Bookmarks are stored in localStorage
- Color tags are stored in localStorage
- Sidebar state is stored in localStorage
