# 📦 Bulk Operations - Quick Reference Card

## 🎯 How to Use

### **Enter Selection Mode**
1. Click the blue "**Select**" button in the header
2. OR press `Ctrl+A` (Windows) / `Cmd+A` (Mac)

### **Select Files**
- Click on any file card to toggle selection
- Checkboxes appear on all files
- Click "**Select All**" in toolbar to select everything

### **Perform Actions**
The toolbar appears at the bottom with these actions:

| Icon | Action | What It Does |
|------|--------|--------------|
| 📥 | **Download** | Downloads single file or creates ZIP for multiple |
| 🔗 | **Share** | Creates share links for all selected files |
| 📁 | **Move** | Moves files to another folder (Coming Soon) |
| 🗑️ | **Delete** | Deletes all selected files (requires confirmation) |

### **Exit Selection Mode**
- Press `Escape` key
- Click "**Select**" button again
- Click **X** on the toolbar
- Action completes automatically

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |

| `Escape` | Exit selection mode |

## 💡 Pro Tips

✨ **Quick Select All**: Press `Ctrl+A` to instantly enter selection mode and select all files

✨ **Mobile Friendly**: Large touch targets and responsive design work great on phones

✨ **Safe Delete**: Confirmation dialog prevents accidental deletion

✨ **Auto-Copy**: Share links are automatically copied to your clipboard

✨ **Smart Download**: Single file downloads directly, multiple files create a ZIP

---

## 📱 Mobile Users

- Tap the "**Select**" button to start
- Tap file cards to select them
- Toolbar sticks to bottom of screen
- Large buttons for easy tapping
- Swipe/scroll works normally

---

## 🎨 Visual Cues

| State | What You See |
|-------|--------------|
| **Selection Mode OFF** | Regular file grid, no checkboxes |
| **Selection Mode ON** | Blue "Select" button, checkboxes visible |
| **File Selected** | Checked checkbox, visual highlight |
| **Files Selected** | Toolbar appears at bottom |

---

## ⚡ Quick Actions

### Download Everything
1. `Ctrl+A` → Select All
2. Click 📥 **Download**
3. ZIP file downloads automatically

### Share Multiple Files
1. Click "**Select**"
2. Click files to share
3. Click 🔗 **Share**
4. Links copied to clipboard

### Clean Up Files
1. Click "**Select**"
2. Click files to delete
3. Click 🗑️ **Delete**
4. Confirm deletion
